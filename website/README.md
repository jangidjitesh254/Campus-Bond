# Campus Bond — Website (Frontend)

Campus Bond's desktop and mobile-responsive web application, built with **React 19**, **Vite**, and **Tailwind CSS**.

## ✨ Key Features
- **Collaboration & Hackathon Hub**: Discover team projects, filter by campus, apply with one click.
- **⚡ AI Skill Matching**: Match your profile skills with projects and discover ideal teammates.
- **Campus Direct Messaging**: Real-time 1-on-1 student conversations and connection requests.
- **Campus Marketplace**: Buy and sell books, notes, drafters, and electronics within the campus.
- **Lost & Found**: Report lost or found campus items with photos and recovery tags.
- **Student Directory & Clubs**: Connect with club heads, explore events, and find peers by branch.
- **Campus AI Assistant**: Ask questions about campus venues, timetables, and clubs.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or newer)
- npm or yarn

### Setup & Run
```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev
```

The application runs by default at `http://localhost:5173`.
API requests (`/api`) and media uploads (`/uploads`) are automatically reverse-proxied to the backend server.

### Build for Production
```bash
npm run build
```
The compiled production bundle is output to `dist/`.
